## Confirmations
- [ ] Goal Steward confirmed the Goal Charter or equivalent task framing.
- [ ] Acceptance evidence maps back to the Goal Charter.
- [ ] Git Steward confirmed current branch and expected task branch.
- [ ] Git Steward confirmed branch base.
- [ ] Git Steward confirmed worktree status.
- [ ] Git Steward confirmed ahead/behind versus `origin/master`.
- [ ] Scope matches the current task, Roadmap, or standing delegation.
- [ ] Only expected files changed.
- [ ] Tests or checks completed.
- [ ] Risks documented.
- [ ] Manual QA documented and Steven accepted it when visual/UI work changed.
- [ ] Secret scan and protected-path review permit a non-force backup push.
- [ ] Nonvisual work qualifies for standing-authorized integration, or Steven accepted the visual work.
- [ ] Merge is fast-forward only; any other strategy has a concrete Steven decision and safety branch.
- [ ] Final report records whether this was standing-authorized or manually accepted.
- [ ] Roadmap `Now` section records the branch as `IMPLEMENTED_PENDING_MERGE` before merge.
- [ ] Post-merge task updates the Roadmap baseline, status, and next action from actual Git evidence.

## Protected Areas
Protected areas require exact task scope and Hard Chew proof. Interrupt Steven before semantic expansion, destructive migration, secret exposure/revocation, or real broker execution.

## Final Merge Decision
Git Steward fast-forwards proven nonvisual work under standing delegation and reports final Git state. Visual/UI work waits for Steven's manual acceptance. Unsafe or non-fast-forward integration interrupts Steven.
