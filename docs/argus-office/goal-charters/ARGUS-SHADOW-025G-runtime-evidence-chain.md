# ARGUS-SHADOW-025G Goal Charter

## Goal

Route candidate lifecycle, continuous plan, runtime source-admission, and
decision-cycle persistence through one dormant topology-bound Engine Host
writer session without activating an installed runtime path.

## Operator Value

Momentum Hunter must not build one market decision from independently writable
or cross-configuration evidence files. Each later stage must prove that its
exact upstream candidate, plan, and admitted source are already persisted under
the same current writer authority before it can append.

## Scope

- Bind all four continuous evidence paths to one program/configuration topology.
- Require one active current host/PID/build/configuration writer session for
  every artifact operation.
- Enforce candidate -> plan -> admission -> cycle stage order and exact
  cross-ledger identity.
- Reject mixed configurations, escaped paths, contradictory evidence, missing
  predecessors, and inactive or replaced writer authority.
- Make exact replay idempotent and permit a restart to continue a valid partial
  prefix without duplication.
- Hold writer authority until an in-flight artifact append finishes.

## Non-Goals

- No installed root, ACL/reparse work, Engine Host importer/startup loop,
  service/scheduler/WPF change, provider/account call, broker/order capability,
  Paper/Shadow activation, production evidence write, merge, or installation.
- No claim that four append-only files form one atomic distributed transaction.

## Acceptance Evidence

- Compileall passes.
- Focused evidence-chain and writer-session tests pass.
- Candidate, plan, admission, cycle, topology, Engine Host, client, and
  automation-supervisor regressions pass.
- Full Python discovery passes within a bounded timeout.
- Diff, protected-path, credential, capability, generated-artifact, and
  canonical nonmutation reviews pass.
