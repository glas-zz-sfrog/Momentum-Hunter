# ARGUS-ROADMAP-003 Goal Charter - Parallel Pipeline Roadmap

## Goal

Turn the authoritative Roadmap into a truthful dependency scheduler that keeps
independent Momentum Hunter development moving while narrow gates continue to
protect provider proof, integration, activation, destructive work, and live
execution.

## Operator Outcome

Steven can open one document and immediately see current runtime truth, every
Ready task, active lanes, exact waiting reasons, integration candidates,
milestone finish lines, and the work that can continue around each gate.

## Scope

- Reconcile canonical Git, all checked-out worktrees, validated branches,
  runtime pins, service/Engine Host, scheduled jobs, Shadow, Alpaca, DATA,
  candle/UI, and protected gates.
- Replace sequential/historical Roadmap structure with the twelve approved
  scheduling sections.
- Define nine lanes, seven milestones, priorities, gate scopes, Ready/Waiting/
  Integration queues, dependency graph, and one-record-per-task inventory.
- Revise branch/worktree concurrency and current-master reconciliation rules.
- Preserve detailed chronology in existing ledgers and release evidence.

## Non-Goals

- No application/test/package/schema/generated-data changes.
- No provider/account/Paper/Shadow/order call or state mutation.
- No service, scheduler, Engine Host, manifest, WPF, credential, or production
  configuration change.
- No merge into canonical master while scheduled runtime pins remain active.
- No worktree/branch cleanup, deletion, reset, stash, rebase, or force push.
