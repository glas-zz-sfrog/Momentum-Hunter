# Goal Charter: ARGUS-AUTOMATION-RUNTIME-IDENTITY-003A

## Goal

Remove total and excluded package-module inventory from authoritative opening
identity while preserving dependency-closure, component-byte, configuration,
environment, loaded-byte, tamper, import-escape, and dynamic-loading authority.

## Operator Value

Opening-unreachable package additions and removals no longer require an
opening runtime promotion. Changes capable of affecting the approved opening
continue to fail closed and require qualification and promotion.

## Scope

- Versioned V2 dependency-closure and runtime-surface fingerprint correction.
- Backward verification of existing V2 release evidence and preserved V1
  rollback behavior.
- Disposable mutation proofs for unreachable and reachable package modules.
- Focused, adjacent, full-discovery, compile, protected-path, and secret checks.
- Isolated and installed physical promotion/runtime-match proof if every prior
  gate passes.

## Exclusions

- Producer-001A and Continuous strategy/runtime semantics.
- Paper, Shadow, RTD, scoring, TradePlans, UI, providers, broker/account/order
  behavior, and the external forensic evidence standard.

## Acceptance

Done means an unreachable package module can be added and removed without
changing closure, surface, or approved opening identity; adding or changing a
reachable module still changes identity; existing V2 and V1 releases remain
verifiable; every existing fail-closed opening protection passes; physical
runtime match is proven; and production authority remains opening-only with
order transmission unavailable.

## Starting Classification

`ACTIVE / BOUNDED OPENING IDENTITY INFRASTRUCTURE`
