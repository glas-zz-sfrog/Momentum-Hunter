# ARGUS-SHADOW-025D Goal Charter

## Goal

Freeze the dormant process-ownership and relative-path topology for continuous
decision evidence without selecting or touching an installed runtime root.

## Operator Value

Momentum Hunter must have one authoritative online writer, one audit trail, and
separate evidence namespaces for engineering and official programs. A service,
frontend, stale Engine Host, or later program must not silently write or reuse
another program's candidate, plan, source-admission, or decision-cycle records.

## Scope

- Assign the Python Engine Host as sole online reader/writer.
- Keep the Windows Automation Service supervisor-only.
- Require WPF to consume versioned Engine Host snapshots rather than files.
- Permit explicit offline review as read-only.
- Derive four distinct append-only paths beneath one absolute caller-provided
  root, scoped by evidence-program and configuration identities.
- Bind append authority to the current Engine Host instance, PID, runtime build,
  configuration, topology, and canonical timestamp.
- Keep the contract prospective, dormant, uninstalled, and nontransmitting.

## Non-Goals

- No actual production root selection, directory creation, persistence, store
  wiring, Engine Host import, service command, scheduler change, WPF change,
  provider/account call, broker/order path, Paper/Shadow activation, or merge.
- No runtime orchestration loop or source-admission persistence implementation.

## Acceptance Evidence

- Compileall passes.
- Focused topology/path/claim/access tests pass.
- Host, service, source, continuous, and adjacent protected regressions pass.
- Full Python discovery passes within a bounded timeout.
- Static capability, credential, runtime-import, generated-artifact,
  protected-path, and diff reviews pass.
- Canonical checkout remains clean and synchronized at its frozen head.
