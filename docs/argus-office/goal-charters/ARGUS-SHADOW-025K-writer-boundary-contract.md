# ARGUS-SHADOW-025K Goal Charter

## Goal

Add a dormant deterministic contract that rejects unsafe installed writer
architectures and names the remaining proof required for a distinct Engine Host
or dedicated evidence-writer boundary.

## Operator Value

Momentum Hunter must not install a raw evidence root behind a cosmetic process
boundary. The contract makes the current same-user design ineligible and keeps
provider credentials, WPF access, process identity, and write authority in the
same reviewable architecture decision.

## Scope

- Model Automation Service, Engine Host, WPF, and evidence-writer identities.
- Keep Automation Service supervisor-only and WPF outside the raw root.
- Require one root-writer process and a writer SID distinct from service, WPF,
  and any separate Engine Host process.
- Evaluate a distinct-principal Engine Host with direct filesystem ownership.
- Evaluate a dedicated evidence writer behind an authenticated nonpersistent
  channel.
- Reject same-SID named-pipe authority, shared secrets, leaked capabilities,
  direct-root bypass, and credential material exposed to WPF or the writer.
- Bind every proposal to the exact root-security policy fingerprint.
- Preserve current-user DPAPI ownership as an explicit architectural constraint.
- Return only `BLOCKED` or `CONTRACT_FEASIBLE_PENDING_PROOF`; never activation.

## Non-Goals

- No Windows identity, service, ACL, root, process, handle, pipe, credential,
  provider, account, broker, order, Paper, Shadow, scheduler, Engine Host, WPF,
  or production-store change.
- No credential reprovisioning decision and no installed architecture selection.
- No merge or install before Tuesday terminal evidence.

## Acceptance Evidence

- Compileall passes.
- Focused same-SID, writer-alias, channel-authentication, capability-leak,
  DPAPI-owner, credential-broker, root-policy, tamper, and non-capability tests
  pass.
- Adjacent SHADOW runtime-chain and full Python discovery pass.
- Diff, protected-path, secret-pattern, capability, generated-artifact, and
  canonical nonmutation reviews pass.
